
# Registro da Prática 01

## Disciplina: Programação Web

### Objetivo

Compreender os conceitos iniciais de desenvolvimento web, a estrutura básica de documentos HTML e a utilização do Git e GitHub para organização e versionamento de projetos.

### Atividades Desenvolvidas

Durante a prática, foram realizadas atividades introdutórias relacionadas à estruturação de páginas HTML, incluindo a utilização de elementos básicos, organização de arquivos e criação de páginas web.

Também foram abordados conceitos de versionamento de código utilizando Git e GitHub, permitindo compreender a importância dos repositórios para o armazenamento e acompanhamento das alterações realizadas nos projetos.

### Conhecimentos Adquiridos

- Estrutura básica de um documento HTML5.
- Utilização de tags HTML.
- Organização de arquivos e diretórios.
- Conceitos básicos de Git e GitHub.
- Importância do versionamento de código.

### Conclusão

A prática contribuiu para a compreensão dos fundamentos do desenvolvimento web e da organização de projetos, estabelecendo uma base para os próximos laboratórios da disciplina.
