# Guia de Comandos Git

Este documento apresenta os quatro comandos básicos do Git utilizados durante as aulas de Programação Web.

## 1. git clone

Utilizado para copiar um repositório remoto do GitHub para o computador local.

```bash
git clone https://github.com/usuario/repositorio.git
```

## 2. git add

Adiciona arquivos à área de preparação (staging), permitindo que sejam incluídos no próximo commit.

```bash
git add .
```

## 3. git commit

Registra as alterações realizadas no repositório local, acompanhadas de uma mensagem descritiva.

```bash
git commit -m "Atualizacao dos arquivos"
```

## 4. git push

Envia os commits do repositório local para o repositório remoto no GitHub.

```bash
git push origin main
```

## Conclusão

Esses comandos são fundamentais para o versionamento de código, permitindo copiar projetos, registrar alterações e manter os arquivos atualizados no GitHub.
