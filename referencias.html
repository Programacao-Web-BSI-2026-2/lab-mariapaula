Tags Básicas

As tags HTML são utilizadas para estruturar o conteúdo de uma página web.

h1 até h6: Definem a hierarquia dos títulos.

p: Define um parágrafo de texto.

br: Insere uma quebra de linha.

Links e Imagens

a: Tag âncora utilizada para criar hyperlinks.

img: Utilizada para inserir imagens em páginas HTML.

O atributo href define o destino de um link, enquanto src indica o endereço de uma imagem.
